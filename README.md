## 🌙 Featured Build — LunahAI

**LunahAI** is a local-first Windows desktop AI assistant I am designing and developing to run supported language models on the user's own hardware. Its public repository includes information about the project and early builds.

[![View LunahAI Repository](https://img.shields.io/badge/VIEW-LUNAHAI%20REPOSITORY-24292F?style=for-the-badge&logo=github&logoColor=white)](https://github.com/HughKnightOCE/LunahAI-Desktop)
[![Releases](https://img.shields.io/badge/DOWNLOAD-PRE--RELEASE-7952B3?style=for-the-badge&logo=github&logoColor=white)](https://github.com/HughKnightOCE/LunahAI-Desktop/releases)

**Areas covered in the project and its early builds:**

- 🧠 **Local inference:** running supported models locally, without relying exclusively on cloud APIs
- 💬 **Desktop interface:** a CustomTkinter-based chat experience with conversation-management workflows
- 🔄 **Model flexibility:** experimenting with Transformers and GGUF backends
- 📄 **Document context:** incorporating local documents into conversations
- 🤝 **Agent workflows:** experimenting with specialist agent pipelines and resource management
- 🎙️ **Voice:** local speech recognition and Windows text-to-speech integration
- 🔐 **Privacy:** exploring network isolation and scoped file access
- 🎮 **Hardware:** testing inference paths and compatibility across consumer GPUs

*LunahAI is evolving software; availability and reliability of individual features depend on the build.*
